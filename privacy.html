WTS backup - Privacy policy

Last updated: 2026-10-08

WTS backup is a personal tool used only by its owner (pjw567890@gmail.com). It is not offered to anyone else.

What it accesses

With the owner's permission, the tool uses the Google Drive API to create, list and verify files inside a folder named "WTS" in the owner's own Google Drive. It uploads market-data archive files that the owner collected on the owner's own computer, and checks their size and MD5 checksum after upload.

What it does not do

  • It does not read, modify, share or delete any other files in the owner's Google Drive.
  • It does not collect, sell or share any personal data with anyone.
  • It does not send any data to any server other than Google Drive.

Storage of credentials

The Google authorization token is stored only on the owner's own computer. Access can be revoked at any time at https://myaccount.google.com/permissions.
